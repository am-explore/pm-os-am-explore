# Contributing to PM OS

Thanks for your interest in PM OS! 🙏

## This Is a Template Repository

PM OS is designed to be **cloned or forked**, not modified via pull requests. Each PM's instance is their own — customized with their product context, metrics, and team information.

**Pull requests will be automatically closed.**

## How to Use PM OS

1. Click the green **"Use this template"** button at the top of the repo
2. Or clone it: `git clone https://github.com/agentmart/pm-os.git`
3. Fill in the `context-library/` files with your product context
4. Start a session with Claude Code or GitHub Copilot

## Found a Bug or Have a Suggestion?

We'd love to hear from you! Please [open an issue](https://github.com/agentmart/pm-os/issues) with:

- **Bug reports:** What happened, what you expected, and steps to reproduce
- **Skill suggestions:** What PM workflow or framework you'd like added
- **Improvement ideas:** What would make PM OS more useful for your workflow

## Adding Your Own Skills

Rather than contributing back to this repo, extend your own copy:

1. Copy `tools/custom-skill-template.md`
2. Create your skill in the appropriate `skills/` subdirectory
3. Add an activation trigger in `CLAUDE.md`

See `tools/README.md` for detailed instructions.
