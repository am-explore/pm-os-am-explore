am-explore field map

The Product Line

A route map through the product development lifecycle — every phase, and the AI skills, reviewer agents, and templates that live there. Two lines run through it: PM OS, the day-to-day product lifecycle, and Agent Production Readiness, which interchanges where a team is shipping an AI agent specifically.

The PM OS line

1

Discover

pm-os-am-explore

Before you scope anything: what's the problem, and whose problem is it.

Skill /discover Opportunity Solution Tree — research signal → validated opportunity
Skill /interview-prep User interview guide, built as a safari not a validation session
Reviewer user-researcher Critiques evidence quality and assumption risk
Watcher risk-monitor Scans early for dependency risk and blockers
Routine user-feedback-synthesis Wednesday 10am — aggregates incoming feedback into themes

Feeds context-library/users.md — personas, JTBD, and research get written back here.

Define & Strategize

pm-os-am-explore

Skill /roadmap Quarterly roadmap planning with explicit tradeoffs

Hook prd-quality-gate Advisory check that fires after a PRD is drafted
3

Design

pm-os-am-explore

Scoped and prioritized. Now make it real enough to react to.

Skill /design-review Structured critique of a mockup, flow, or prototype
Reviewer designer-reviewer UX quality, design-system fit, flow gaps
Watcher assumption-validator Names the assumption you're betting on before you build
4

Build & Ship

pm-os-am-explore

Design's validated. This is where execution discipline and decision hygiene matter most.

Skill /setup-routine Turn a recurring build-phase task into a scheduled routine
Template decision-template.md Single-decision quick log
Template roi-impact-estimation.md Business case before committing engineering time
Reviewer engineer-reviewer Feasibility, tech debt, implementation risk
Log decision-log/ Institutional memory — every decision, with rationale
⇄ Interchange — if what you're building is an AI agent rather than a static feature, this is where the Agent Production Readiness line takes over. Continue to Gate Check.

The Agent Production Readiness line

A

Gate Check

agent-production-readiness-framework

Before an agent gets more autonomy than a static feature ever had, it has to earn it.

Checklist PROMOTION_GATE_CHECKLIST.md Sign-off record for all 4 promotion gates
Doc promotion_gates.md Golden evals → shadow traffic → canaried HITL → telemetry
Schema eval_benchmark_schema.json Machine-readable format for golden eval benchmarks
Example eval_benchmark_examples.json Sample cases across reasoning, tool-calling, safety, boundary
B

Drift Watch

agent-production-readiness-framework

It's live. Now prove it's still behaving, every day, without a human reading every trace.

Script drift_evaluator.py LLM-judge worker with a circuit breaker on pass-rate drift
Example sample_production_traces.jsonl Sample trace file to run the evaluator against out of the box
⇄ Rejoins the PM OS line near Launch — a passing drift check is part of what "launch readiness" means for an agent.
